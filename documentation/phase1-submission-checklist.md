# Phase 1 Submission Checklist

Use this checklist before submitting the Phase 1 progress report on Blackboard.

## Required Report Content

- [ ] Cisco Packet Tracer installation screenshot is included.
- [ ] The screenshot shows system evidence such as username, date, or time.
- [ ] Objectives of using Cisco Packet Tracer are described.
- [ ] Advantages of Packet Tracer for this project are described.
- [ ] One key decision is explained, including why it was made.
- [ ] One genuine problem encountered is described.
- [ ] The problem status is stated as resolved or in progress.
- [ ] The plan for the next project period is listed.
- [ ] Each group member's name and specific contribution are included.

## Project Artifacts Section

The final report should contain a section titled **Project Artifacts** with:

- [ ] Live Google Docs or Word Online report link
- [ ] GitHub repository link
- [ ] Packet Tracer `.pkt` file link or Blackboard attachment

Suggested format:

```text
Project Artifacts

Live report document: [insert shared Google Docs / Word Online link]
GitHub repository: https://github.com/AeyOC/university-campus-wan-packet-tracer
Packet Tracer project file: https://github.com/AeyOC/university-campus-wan-packet-tracer/blob/main/CS360_Project-Phase%201.pkt
```

## Version-Control Transparency

The initial Packet Tracer work was created locally before structured version control was introduced. Do not alter timestamps or create misleading historical commits. Repository changes from this point should use clear commit messages and actual timestamps.

## Blackboard Submission

Recommended items to submit:

1. Phase 1 progress report in PDF format
2. Packet Tracer `.pkt` file
3. Google Docs / Word Online live link
4. GitHub repository link

Before submission, test all shared links in a private/incognito browser window to confirm the instructor can access them.
